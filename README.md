# Kingshot Assistant

**简体中文** | [English](README.en.md)

[在线使用](https://link6.github.io/kingshot-assistant/) · [下载桌面版](https://github.com/Link6/kingshot-assistant/releases/latest) · [桌面版构建](https://github.com/Link6/kingshot-assistant/actions/workflows/desktop.yml)

Kingshot 集结同步与王城补兵计时助手，支持中文、英文和 Electron 桌面版。单机计时无需账号，计算在设备本地完成，常用输入自动保存在本机。房间协作需通过 Discord 成员验证，主动共享的战况和行军时间保存在 Supabase 并同步给房间成员。

本项目采用 [MIT 开源许可证](LICENSE)，版权归属 © 2026 Link6。

## 功能

- **集结同步**：按每位车头的集结准备时长和行军时间，计算各自发起集结的时刻，让多队同时到达同一目标。支持自动安排或指定共同到达时间。
- **实际开车校准与间隙分析**：排程后可逐队微调 ±0.1 / ±1 秒、记录现在发起，或填写实际发起时刻。仅修改当前车头，预计到达随之变化，并完整显示相邻集结预计到达之间的敌方补兵驻防时间间隙，不扣除误差；防守补兵仍按本人设置扣除两端容错。
- **UTC 时钟与时间表**：显示当前 UTC 时间，按发起顺序列出车头，一键复制简短的「名字 + UTC 发起时间」，方便粘贴给队友。
- **王城补兵**：记录敌方倒计时，计算相邻两次攻击之间的补兵出征窗口，自动扣除自己的行军时间和窗口两端的容错。
- **防守反集结**：选择要跟随的敌方攻击及已有／新增我方车头，设置在敌方到达后多少秒命中，倒推开车时间。支持记录已经在集结或行军的游戏剩余读数、±0.1／±1 秒和实际发起校准；显示目标落点、预计落点及提前／延后偏差。防守时间轴同时显示我方准备、行军、实际落点和计划目标，本地与房间均支持，并可选择 10／30 秒近景。敌方修改、重新记录、停止或车头资料变化会提示核对，已记录进度保持，由指挥显式重新对齐或停止；不会自动重排已发起的反集结。房间由房主／指挥操作，车头在“我的行动”看个人反集结，其他成员继续看补兵提示。
- **补兵加速道具分析**：普通出征时间已过时，继续显示尚未结束的到达窗口，估算 25%／50% 行军道具的最少件数组合，并给出仅用 25% 或仅用 50% 的可行方案、预计耗时、出征区间和最迟出征倒计时。同件数优先少用 50% 道具。可填个人可用数量（留空不限、0 表示不使用）及操作预留，设置仅保存在本机；房间内按本人行军时间分析，不增加数据库更新。
- **实时倒计时与微调**：记录后立即倒计时，集结结束自动转为行军；使用 `−1 / −0.1 / +0.1 / +1 秒` 按钮校准已记录的时间。
- **敌方停止与重新发起**：敌方取消集结时可停止该队计时，立即移出补兵窗口，保留队伍资料。重新发起时读取新倒计时并重新记录。本地和房间防守均支持，房间内由房主或指挥操作并同步给全员。
- **窄窗口警告**：扣除容错后，可用补兵窗口大于 0 且小于 1 秒时显示黄色警告：**可能补兵失败，注意医院容量。**
- **战场时间轴**：王城补兵倒计时下方滚动显示未来 60 秒，分别标出点击出征窗口、援军到达窗口和逐队敌方到达时刻。窄窗口标黄，无安全间隙标灰；点击色带查看完整 UTC 时间范围。记录、微调和有效的行军／容错修改会立即更新。
- **房间战场时间轴**：进攻集结逐队显示发起、集结准备、行军和到达间隙，突出本人的车头；防守显示普通出征、个人加速方案、援军到达窗口和逐队敌方到达。进攻自动扩大到完整排程，防守默认未来 60 秒，均可手动选择 1／3／6／10 分钟。点击色带或时间点查看 UTC 详情。使用房间服务器校时，平滑滚动，校准和停止记录后立即更新；断线、待命或排程失效时暂停，不写入数据库。
- **独立房间作战**：指定 Discord 服务器成员通过 8 位房间码进入独立界面。本地名单与计时不注入房间。登录后默认使用 Discord 显示名（无显示名时使用用户名），可手动修改房间昵称。成员默认是 joiner，只更新并确认行军时间，查看“我的行动”。房主和指挥选择车头、设置集结准备、统一发布排程并校准实际开车，或切换防守维护敌方读数；每人按自己的行军获得补兵提示。指挥可广播文字指令并要求重新核对行军。后台限制房间容量、有效期和更新额度；倒计时在客户端运行。[部署和权限说明](supabase/README.md)
- **个人宠物与行军保留**：房间内切换模式不再重复要求更新行军。本人可在“我的行军时间”下填写宠物已开启分钟数、更新或结束个人倒计时，刷新保留在当前浏览器。宠物结束前提示检查行军读数，未变化无需重填。
- **中英文与桌面支持**：切换语言不重置计时；Electron 版提供窗口置顶、精简小窗、窗口位置记忆和后台系统提醒。

## 怎么用

### 多个车头同时到达

1. 在「集结同步」添加车头，填写昵称、集结准备时长和到同一目标的实际行军时间。
2. 选择「自动安排」，设置最早开车前的准备时间；也可选择「指定到达时间」。指定时间的输入使用**设备本地时间**，排程结果显示为 UTC。
3. 点击「生成开车倒计时」，按提示发起集结。这里的开车时刻指**点击发起集结的时刻**。
4. 在大倒计时下方的「UTC 集结时间表」点击「一键复制时间表」，粘贴给队友。按钮始终显示，生成排程后即可使用。

复制内容示例：

```text
车头A 12:30:05 UTC
车头B 12:30:15 UTC
车头C 12:30:20 UTC
```

复制内容只包含名字和发起时刻，不包含日期、序号或共同到达时间；时间显示为 `HH:mm:ss UTC`，不显示小数秒，内部计时仍保留原精度。修改名单或设置后，需要重新生成排程；在此之前，倒计时和复制内容仍使用原排程。

### 在两波攻击之间补兵

1. 在「王城补兵」填写自己的实际行军时间，以及窗口两端各留出的容错。
2. 添加至少两支敌方队伍，选择「集结中」或「行军中」。集结剩余默认按「分:秒」输入和显示（例如 `5:00`），行军时间独立填写、显示和微调。集结期间保留完整行军时长，集结结束后转为行军剩余倒计时；补兵窗口按两段时间的合计计算。本地与房间均支持。
3. 当游戏倒计时走到输入读数时，点击该队的「记录现在」。记录后立即显示实时倒计时，可直接与游戏对照。
4. 如有偏差，用微调按钮修改当前记录：`＋` 延后，`−` 提前。修改立即更新预计攻击到达时间和补兵窗口，不重置已走过的时间，也不影响其他队伍。集结阶段结束后，只能微调行军时间。
5. 按补兵提示点击出征。显示的是**你发兵的时刻**，已经扣除了自己的行军时间。

上方输入保留用于下次记录。重新记录只替换当前队伍的记录。容错扣除后没有可用间隙时，不提供可用补兵窗口；窗口不足 1 秒时会显示黄色警告。

时长支持 `5:00`、`35`、`29.5秒`、`4m 40s` 等格式；纯数字按秒计算。

加速分析按「尚未出征」计算。默认出征前预留 1 秒、使用每件道具前再预留 1 秒；先用 50%，再用 25%，每次对当时剩余时间扣减。具体操作越早或越晚都会改变到达时间，需按显示的出征区间和顺序执行，并以游戏读数核对。道具按剩余时间减少的说明可参考 [Quick March I](https://kingshotwiki.com/items/quick-march-i/) 和 [Quick March II](https://kingshotwiki.com/items/quick-march-ii/)。

### 车头宠物估计计时

「集结同步」和「王城补兵」中，每位车头都有独立的宠物估计计时。看到车头已开宠物时，填写估计已开启的分钟数，再点「发现已开宠物」。不知道已开多久就填 `0`，按发现时刻估算最晚结束时间；实际可能更早结束。

- 按 2 小时持续时间计算，预计结束前 **5 分钟**显示黄色提醒。开启声音时会提示一次，桌面版也会安排后台提醒。
- 提醒会列出需要核对的车头；点击「去更新行军时间」可跳到输入处。按游戏实际读数更新行军时间；集结同步需重新生成排程，王城补兵需重新记录攻击，本工具不会自动推算宠物失效后的行军速度。
- 可填写新的已开启分钟数并点击「应用新的估计」。确认宠物结束后点击「标记已结束」清除该队计时和提醒。
- 宠物计时按绝对时间保存在本机，刷新、切换语言、重新生成排程或重新记录攻击不会重置。设备时间发生明显变化时会要求重新核对估计。

### 手机添加到主屏幕

网页安装名称跟随页面语言：中文为 **Kingshot 战术计时助手**（短名称 **战术计时**），英文为 **Kingshot Timing Assistant**（短名称 **Kingshot Timer**）。首次访问按浏览器语言选择，非中文语言使用英文；保存的语言选择优先。切换语言会同步更新安装配置和 Apple 主屏幕名称，两种语言保持同一应用标识，离线也可切换。已经安装的应用名称由浏览器管理，不保证切换后立即改名。

保留浏览器原生的应用安装提示，不拦截 `beforeinstallprompt` 事件，也不自动显示网页自制提示条。浏览器提供安装能力后，页面底部显示「安装应用」，点击会直接调用浏览器原生安装弹窗；安卓和桌面浏览器均可使用。

原生提示是否自动出现、出现时机和取消后的再次提示由浏览器决定，网页不会在进入页面或点击无关功能时强行弹出。未提供原生安装能力的手机浏览器可从页面底部主动打开「安装帮助」；iPhone 显示 Safari 操作步骤，微信等内置浏览器提示先在系统浏览器中打开。以主屏幕应用方式启动或使用 Electron 时隐藏安装入口。安装不会消除后台计时和声音提醒的限制。

## 本地运行

需要 Node.js 24 或更新版本。网页无第三方运行依赖，无需先执行 `npm ci`。

```sh
git clone https://github.com/Link6/kingshot-assistant.git
cd kingshot-assistant
npm start
```

打开 [http://localhost:4173](http://localhost:4173)。也可直接打开 `dist/index.html`；离线缓存需要 HTTP/HTTPS。

运行检查：

```sh
npm test
```

## Electron 桌面版

直接使用请前往 [Releases](https://github.com/Link6/kingshot-assistant/releases/latest) 下载对应系统的可执行文件。Windows 提供安装版和免安装便携版，下载后无需安装 Node.js。

桌面应用名称统一为 **Kingshot Assistant**，每个平台提供一套下载包，界面和窗口标题可切换中英文。Windows 程序、安装器和卸载程序，macOS 应用与 DMG，以及 Linux AppImage 均使用项目的金色「K」图标；Windows 构建会核对实际 EXE 中各尺寸的图标资源。

安装开发依赖并启动：

```sh
npm ci
npm run desktop
```

在对应系统上打包：

| 系统 | 命令 | 输出格式 |
| --- | --- | --- |
| Windows | `npm run dist:win` | 安装版 EXE、便携版 EXE |
| macOS | `npm run dist:mac` | DMG |
| Linux | `npm run dist:linux` | AppImage |

安装依赖时需要下载 Electron 运行时，打包也可能需要下载构建工具。成品输出至 `desktop-release/`。当前未配置代码签名、macOS 公证和自动更新。

也可在 GitHub Actions 的 [Build desktop apps](https://github.com/Link6/kingshot-assistant/actions/workflows/desktop.yml) 页面手动运行工作流。完成后，在该次运行的 Artifacts 区域下载对应的 `desktop-windows-latest`、`desktop-macos-latest` 或 `desktop-ubuntu-latest`。推送与 `package.json` 版本一致的 `v*` 标签时，三个平台构建通过后会自动发布 Release，附上可执行文件和 SHA-256 校验值；发布说明保存在 `release-notes/<标签>.md`。

## GitHub Pages 部署

仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。推送到 `main` 后，[Deploy GitHub Pages](.github/workflows/pages.yml) 会先运行测试，再部署 `dist/`。

资源路径、离线缓存和本地存储支持 `/kingshot-assistant/` 项目路径。脚本和样式使用内容哈希文件名，发布时自动生成，避免新页面混用旧资源。联网时普通刷新优先读取最新页面；断网时使用完整的离线缓存版本。更新不会自动重载正在计时的页面。

修改网页源文件后运行 `npm run prepare:web` 生成配套资源；本地服务器、测试、桌面打包和 GitHub Pages 发布也会自动生成。

## 数据与计时说明

- 单机模式的常用输入保存在当前浏览器或桌面应用本地，不同设备、域名及网页与桌面版之间不会自动同步。加入房间后，共享战况和队友时间从服务器同步；退出房间恢复个人输入。
- 切换语言保留当前计时；刷新恢复输入和宠物估计计时，但需要重新生成集结排程或记录攻击战况。设备睡眠恢复或检测到明显时钟跳变时，会清除集结排程和攻击记录；宠物估计保留，时钟变化后需重新核对。
- UTC 根据设备时钟换算，不是从游戏服务器读取的时间。使用前请确保设备时间准确。
- 本工具根据手动输入计算，不读取或操作游戏。补兵按「援军在两次敌方攻击之间到达王城」计算，实际结果仍受游戏延迟和操作时刻影响，需结合实战核对。
- 网页实战请保持在前台；后台或锁屏可能延迟提醒。提示声音只针对当前显示的功能，桌面后台提醒还受系统通知设置影响。
