# Kingshot Assistant v0.2.7

## 简体中文

- Windows 安装版、便携版、安装后的程序和卸载程序使用项目的金色「K」图标。
- macOS 应用与 DMG、Linux AppImage，以及桌面窗口和系统提醒使用同一项目图标。
- 桌面应用名称统一为 **Kingshot Assistant**，每个平台保留一套下载包；软件界面和窗口标题继续支持中英文切换。
- 包含网页安装名称随所选语言切换的更新，以及 MIT 许可证和 SHA-256 校验值。

## English

- Windows installer, portable executable, installed application, and uninstaller use the project's gold K icon.
- The same icon is used for the macOS app and DMG, Linux AppImage, desktop windows, and notifications.
- The desktop product name remains **Kingshot Assistant**, with one set of downloads per platform. The interface and window title still support Chinese and English.
- Includes localized web installation names, the MIT license, and SHA-256 checksums.

## Downloads / 下载

- Windows x64: Setup installer or Portable executable / 安装版或免安装版
- macOS Apple Silicon: ARM64 DMG
- Linux x64: AppImage
- LICENSE: MIT license / MIT 许可证
- SHA256SUMS.txt: file checksums / 文件校验值
