# Kingshot Assistant v0.3.4

## 简体中文

- 接通桌面版房间协作，支持创建、加入和找回房间，以及现有的共享战况和计时功能。
- 桌面 Discord 授权改为使用系统默认浏览器，可沿用浏览器中已有的 Discord 登录状态。
- 授权后经随机本机端口和本次登录独立的 state 安全返回桌面，通过 PKCE 换取会话。
- 新增桌面“取消登录”按钮，支持取消、超时、失败后重试；不再弹出独立的 Discord 账号密码窗口。
- 继续检查 Discord 服务器成员资格及房间权限；不读取或复制浏览器 Cookie。

## English

- Desktop battle rooms now support creating, joining, and recovering rooms with the existing shared battle and timing features.
- Desktop Discord authorization now uses the default system browser and its existing Discord sign-in.
- A random loopback port, a per-attempt state, and PKCE return authorization to the desktop app.
- Added Cancel sign-in with timeout and failure recovery, replacing the separate embedded Discord login window.
- Discord membership and room role checks remain in effect. Browser cookies are not read or copied.
