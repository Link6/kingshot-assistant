## 中文

Kingshot Assistant 首个公开桌面发行版，支持中文和英文。

- 集结同步：按车头的集结准备与行军时长，计算发起时间，让多队同时到达。
- 实时 UTC 时钟；一键复制「车头名字 + UTC 发起时刻」的简短时间表。
- 王城补兵：记录敌方倒计时，自动计算两波攻击之间的出征窗口。
- 记录后实时倒计时，支持 ±1 秒、±0.1 秒校准；补兵窗口不足 1 秒时黄色提示，并提醒留意医院容量。
- 桌面窗口置顶、精简小窗、后台系统提醒，以及完整中英文 README。

### 下载

- **Windows 64 位**：`Kingshot-Assistant-Setup-0.2.3-x64.exe` 为安装版；`Kingshot-Assistant-Portable-0.2.3-x64.exe` 为免安装便携版。
- **macOS**：下载 `.dmg` 文件，架构以文件名为准。
- **Linux**：下载 `.AppImage` 文件，赋予执行权限后运行。
- `SHA256SUMS.txt` 提供上述文件的 SHA-256 校验值。

当前应用未进行代码签名或 macOS 公证，系统可能显示来源提示；不支持自动更新。请从本 Release 下载，后续版本需手动更新。

## English

The first public desktop release of Kingshot Assistant, with Chinese and English interfaces.

- Coordinate multiple rally leaders to reach the same target together.
- View the live UTC clock and copy a compact list of leader names and UTC rally start times.
- Record enemy countdowns to calculate reinforcement send windows between consecutive attacks.
- Compare live countdowns with the game and adjust recorded times by ±1 or ±0.1 seconds. Windows under 1 second show a yellow warning and a hospital-capacity reminder.
- Always-on-top and compact desktop modes, background system notifications, and full Chinese and English documentation.

### Downloads

- **Windows 64-bit:** `Kingshot-Assistant-Setup-0.2.3-x64.exe` is the installer; `Kingshot-Assistant-Portable-0.2.3-x64.exe` runs without installation.
- **macOS:** Download the `.dmg`; check its filename for the architecture.
- **Linux:** Download the `.AppImage`, make it executable, and run it.
- `SHA256SUMS.txt` contains SHA-256 checksums for these files.

Builds are unsigned and not notarized for macOS, so your operating system may show an unidentified-source prompt. Automatic updates are not configured. Download from this Release and install future versions manually.
