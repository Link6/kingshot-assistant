# Kingshot Assistant v0.3.1

## 简体中文

- 新增桌面更新面板：启动后自动检查新版本，也可手动检查。
- Windows Setup 安装版和 Linux AppImage 支持应用内下载、显示进度、校验更新包，再选择安装重启。
- 下载后不会在普通退出时自动安装；安装前提示会结束当前计时，可选择稍后处理。
- Windows 便携版和当前未签名的 macOS DMG 支持检测新版并打开下载页。
- 从旧版本升级到本版本需先手动下载安装一次，此后的 Windows 安装版可使用应用内更新。
- 包含房间协作、防守反集结、车头启停、实际读数校准及战场时间轴等最新功能。

## English

- New desktop update panel with startup and manual checks.
- Windows Setup and Linux AppImage editions download updates in-app, show progress, verify the package, and offer installation and restart.
- Downloaded updates are not installed on ordinary exit. Installation requires confirmation because it ends active timers.
- Windows Portable and the current unsigned macOS DMG check for releases and open the download page.
- Older versions need one manual installation of this release before in-app updating becomes available in supported editions.
- Includes the latest battle rooms, counter rallies, leader toggles, actual-reading calibration, and battlefield timelines.

## Downloads / 下载

- Windows x64: **Setup recommended / 推荐安装版**; Portable supports manual installation.
- macOS Apple Silicon: ARM64 DMG, manual installation.
- Linux x64: AppImage.
- Update manifests and blockmaps are used by the app; users do not need to download them manually.
- LICENSE and SHA256SUMS.txt provide the MIT license and checksums.
